# Codebook

- `code/01_genetics/`: locus alignment, signed-LD fine-mapping, `coloc.susie`, external eQTL and FinnGen analyses, response-state and cross-autoimmune context.
- `code/02_single_cell/`: BAM-to-count reconstruction, adaptive cell calling, SoupX correction, conservative annotation, donor-level pseudobulk and leave-one-donor-out analysis.
- `code/03_bulk_proteomics_pharmacology/`: bulk validation, pathway meta-analysis, proteomic robustness/confounding and TYK2 locus sensitivity.
- `code/04_figures/`: repository-relative scripts for Figures 1–7 and Supplementary Figures S3–S13.
- `data/derived/figures/`: compact plotted values; direct identifiers and raw sequence data are excluded.
- `data/derived/analysis/`: compact analysis outputs organized by genetics, molecular QTL, single-cell, bulk, proteomics, pharmacology and evidence domains.
- `data/raw/`: user-supplied upstream data; excluded from version control.
- `work/`: regenerated intermediate results; excluded from version control.
- `data/metadata/`: data-source and figure manifests.
- `audit/`: source-project inventory, inclusion/exclusion decisions and release checks.
- `manifests/`: asset mapping, code index and cryptographic checksums.
- `results/figures/`: committed reference renders.
